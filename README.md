# Aggregate Summarizer

A production-ready multi-LLM document inference platform that orchestrates concurrent document summarization across multiple AI providers, evaluates generated summaries using semantic and operational metrics, and produces a final consolidated summary through an asynchronous processing pipeline.

**Live Pilot Service:** https://aggregatesummarizer.com

---

## Overview

Aggregate Summarizer enables users to compare document summaries generated by multiple Large Language Models (LLMs) in a single workflow.

Rather than relying on a single AI model, the platform concurrently orchestrates multiple providers, benchmarks their outputs using semantic and operational metrics, and synthesizes a consensus summary to help users obtain a more reliable overview of their documents.

The platform currently supports PDF, DOCX, and TXT documents with multilingual document processing.

---

## Features

- Multi-LLM document summarization
- Concurrent inference across multiple providers
- Consensus summary generation
- Semantic evaluation and quality metrics
- PDF & DOCX export
- Multilingual document support
- Asynchronous backend processing
- Production deployment on AWS

---

## General Architecture

```
Document
    │
Parser
    │
Chunking
    │
Concurrent Multi-LLM Inference
    │
Summary Evaluation
    │
Consensus Generation
    │
Export & API
```

The system is designed around modular provider abstraction, allowing new LLM providers to be integrated with minimal changes to the orchestration pipeline.
